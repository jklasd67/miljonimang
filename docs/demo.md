# Lõppdemo kirjeldus

Demo põhivoog:
1. Avan rakenduse ja näitan ülesannete nimekirja.
2. Valin ülesande.
3. Näitan, et küsimused tekivad assignment.md + lahendusfailide põhjal.
4. Mängin vähemalt 3 küsimust.
5. Kasutan ühte õlekõrt.
6. Näitan tulemuse vaadet.
7. Lisan input kausta uue numbrilise ülesande ja näitan, et see ilmub menüüsse.
