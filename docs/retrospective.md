# Retrospektiiv

## Mis õnnestus
- Arhitektuur sai jaotatud eraldi teenusteks.
- Miinimumnõuded said kaetud ühes MVP versioonis.
- Uue ülesande lisamine input kausta töötab ilma koodi muutmata.

## Mis oli keeruline
- Heade arusaamisküsimuste loomine ilma päris LLM API-ta.
- Tasakaal lihtsate ja keerukate küsimuste vahel.

## Mida parandada järgmises iteratsioonis
- Lisada päris AI API integratsioon.
- Salvestada küsimused vahemällu.
- Lisada kasutajate tulemuste ajalugu ja õpetaja statistika.
