# Definition of Done

Töö loetakse valmis, kui:
- Funktsionaalsus vastab kasutajaloo vastuvõtutingimustele.
- Kood on jagatud loogilisteks osadeks (faililugemine, küsimused, mänguvaade).
- Vähemalt üks manuaalne test on tehtud ja tulemus dokumenteeritud.
- README on uuendatud.
- Teadaolevad piirangud on dokumenteeritud.
