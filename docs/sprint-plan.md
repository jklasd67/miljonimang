# Sprint Plan

## Sprint 1 eesmärk
Valmis saada MVP, mis katab miinimumnõuded:
- ülesannete lugemine input kaustast,
- küsimuste genereerimine,
- miljonimängu vaade,
- tulemuse kuvamine.

## Sprint 1 ulatus
1. Backend API
2. Frontend mänguvaade
3. Fallback küsimuste generaator
4. Prompti dokumenteerimine
5. README

## Arendusjärjekorra põhjendus
- Esmalt faililugemine, sest see on kogu süsteemi sisend.
- Seejärel küsimuste teenus, et mängul oleks andmed.
- Lõpuks UI, et kasutusvoog oleks terviklik.

## Definition of Ready (lihtsustatud)
- Kasutajalugu on kirjeldatud kujul "Kasutajana tahan..., et...".
- Vastuvõtutingimused on kirjas.
- Tehniline sõltuvus on teada.
